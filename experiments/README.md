# Experiments

This is the heart of **Cooking by the Book**: cooking as an open-ended, repeatable experiment.

A test can be a simple side-by-side bread bake, a coffee extraction comparison, a historical recipe reconstruction, a fermentation trial, or an experimental two-network food material. No single technique defines this project.

Add experiments by copying [TEMPLATE.md](TEMPLATE.md). Use the next available ID, but record each run separately (e.g. EXP-001-R01 and EXP-001-R02). Failures count as results.

## Working rules

- **Question first:** write down exactly what you are trying to learn.
- **Controls matter:** change one independent variable when possible and include a baseline.
- **Record actual numbers:** grams, time, temperature, pH, concentration, RCF (×g), rotor, photo times, etc.
- **Keep predictions and observations separate.** Untried recipes must say *proposed*.
- **Measure outcomes:** texture, yield, flavour, cost, appearance, and relevant safety observations.
- **Do not over-standardize:** quick kitchen trials can be shorter than laboratory-style investigations.
- **Record failures and surprises.** Do not silently replace the original recipe with the latest result.
