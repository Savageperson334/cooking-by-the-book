# Food science and mechanism library

This folder is a reading and reference notebook, **not** a list of verified recipes.

## Mechanism index

| Mechanism | What to investigate |
|---|---|
| Crystallization | Nucleation, seeding, polymorphs, impurity exclusion, supersaturation |
| Wax and lipid networks | Oleogels, bigels, emulsion stability, phase connectivity |
| Enzymatic restructuring | Proteases, amylases, pectin methylesterase vs pectin depolymerases |
| Plant pigments | pH response, enzymatic browning, oxidation, pigment complexation |
| Colloids | Cloud stability, tea cream, precipitation and phase separation |
| Diffusion and transport | Moisture, oxygen access, enzyme penetration, delayed activation |
| Traditional food chemistry | Historic fermentation, milk clotting, pickling, sugar and starch techniques |

## How to record a paper

**Citation:** title, author(s), year, journal, DOI/stable link.  
**What was actually measured:** specific formulation, method, result, conditions.  
**How strong is the evidence?** controls, replication, limitations.  
**Potential application:** clearly mark as hypothesis until tested.  
**What should we test first?** smallest useful experiment that isolates the mechanism.

Avoid invented citations, broad claims unsupported by the actual source, or presenting technical material-processing conditions as safe culinary protocols.
